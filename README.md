# TabBuilder

> Scaffold professional projects in seconds — right from VS Code.

## ✨ Features

- **21 frameworks** across Java, Python, C#, PHP and JavaScript/TypeScript
- **5-step wizard**: Framework → Architecture → Database → DevOps → Summary
- **Architecture patterns**: MVC, Clean Architecture, Hexagonal, DDD
- **DevOps in one click**: Docker, Kubernetes, GitHub Actions, Azure Pipelines
- **Framework-specific READMEs** with real commands, not generic templates
- **Runtime checks**: warns if Java, Python, .NET, etc. is not installed
- **Auto install**: runs `npm install`, `dotnet restore`, etc. in the integrated terminal
- No internet connection required · No AI · No API keys

## 🚀 Quickstart

1. Open the **TabBuilder** panel in the activity bar (or press `Ctrl+Shift+N`)
2. Enter a project name and select a folder
3. Choose your framework, architecture, database and DevOps option
4. Click **Generate project**
5. Open the project — done!

| Option | Files generated |
|--------|----------------|

| Kubernetes | Dockerfile + `k8s/` (deployment, service, ingress, configmap, secrets) |
| GitHub Actions | `.github/workflows/ci.yml` |
| Azure Pipelines | `azure-pipelines.yml` |
